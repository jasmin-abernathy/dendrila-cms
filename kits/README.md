# Kits fonctionnels

Les dossiers de `kits/` décrivent uniquement une structure fonctionnelle de départ : types de contenu, modules, navigation et politiques.

Ils ne décrivent pas une esthétique. Le résultat graphique est choisi séparément dans `design-styles/`.

Par défaut, tous les styles sont compatibles avec tous les kits. Un besoin particulier doit être exprimé comme une capacité technique, jamais comme une catégorie métier.
