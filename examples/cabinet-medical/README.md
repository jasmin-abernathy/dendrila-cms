# Démonstration de site de cabinet RésoSoin

Ce dossier décrit le contenu public synthétique utilisé par les prototypes RésoSoin.

- Cabinet : **Cabinet des Jardins · démo**
- Ville : **Metz**
- Profil présenté : **Dr Camille Martin**, médecin fictive de démonstration
- Activité : médecine générale
- Coordonnées, adresse, horaires et disponibilités : à fournir par les fixtures explicitement fictives de l’application ; aucune coordonnée réelle n’est publiée ici.

Le kit Dendrila correspondant est `kits/cabinet-medical/kit.json`. Il sert à amorcer les pages publiques et ne configure ni réservation réelle, ni dossier patient, ni connecteur d’agenda.

Les modules de contenu éditorial restent dans Dendrila CMS. Les rendez-vous et données de santé relèvent d’un service distinct ; ils ne doivent pas être synchronisés dans le contenu public du cabinet.
